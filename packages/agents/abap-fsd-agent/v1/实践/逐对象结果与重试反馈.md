# 逐对象结果与重试反馈

规则编号：BP-002。触发：逐行或逐对象批量反馈；无操作的只读列表不强加红绿灯。

### 6.2 消息反馈

业务状态与全部消息按稳定键关联，支持一行多条消息。错误优先于警告和成功；后续成功消息不能掩盖前一步失败。保留真实标准消息编号及变量；本地校验不编造SAP编号。未处理、失败、结果未知、部分完成必须区分。

## 具体约束

每个对象分别保存步骤结果与消息集合，状态区分未处理、处理中、成功、失败、部分完成、结果未知。全部目标动作成功才显示成功；已保存但审批失败显示真实部分完成。整单失败映射到涉及的项目，不以当前屏幕行号定位。

消息保留实际类型、编号、变量和文本；末尾成功不能覆盖前面错误，清理失败另记不掩盖主错误。查看明细能读取全部消息。前台需求要求弹框时不擅自替换为日志链接；后台不强加弹框。

重试入口说明可重试对象、不能重试的成功动作、未知结果核对及刷新时点。输出作为rules及tests，接口也应同步errorContract/partialFailureRecovery。

验收：一对象多消息、排序后定位、未处理不能变成功、A成功B失败重试不重复A、结果未知不能直接重发。
