# 接口功能说明书渲染合同

输入：i.schema.json校验后的I规格。执行通用章节与来源映射，不让模型另写一套事实。

## 1 需求说明

呈现purpose、scope、requirements及来源。标题使用真实title；没有开发项时使用specId，不猜项目编号。

## 2 功能规范

按fields.direction及contract中的字段引用输出完整字段表，列出业务含义、类型/精度、必输/默认、来源目标、校验及单位。按messageStructure.path呈现消息层级、基数、输入输出；列发送接收方、方向、触发与版本。

## 3 业务逻辑

依次呈现本类型contract：direction、sender、receiver、interaction、trigger、protocolAndFormat、contractVersion、messageStructure、mappingRuleIds、successDefinition、transactionBoundary、idempotency、ordering、timeoutRetry、partialFailureRecovery、errorContract、monitoringAndReconciliation、volumeAndLatencyTarget。对应rules按业务路径展开，同一规则ID仅定义一次；所有decision渲染其建议/已确认/未知状态，未知链接issueIds。

## 4 开发测试数据

按tests列出场景、前置、输入、明确预期和方法，展示requirementIds/ruleIds追溯。不得使用“正确”作为唯一预期，不将方案走读变成运行通过。

## 附属信息

从公共映射渲染核验摘要、真实证据定位、所有非resolved问题和确认状态。Schema合格不自动添加“可直接开发”或已上线结论。

验收：每个contract字段有可读落点、引用唯一、关键未知仍可见、无空模板指导语。
