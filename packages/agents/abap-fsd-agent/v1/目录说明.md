# ABAP FSD 提示词入口

**日常修改先打开 [主提示词.md](主提示词.md)。**

它集中定义角色、业务分析、提问策略、证据、阶段与表达。保存 UTF-8 Markdown 后，下一次模型调用读取新内容，不需要修改 manifest 哈希或重启 API。

完整结构、阶段操作、修改示例和测试方法见 [提示词工程完整方案.md](提示词工程完整方案.md)。

| 想改什么                 | 修改哪里                             |
| ------------------------ | ------------------------------------ |
| 定位、分析、提问、表达   | [主提示词.md](主提示词.md)           |
| 讨论回复                 | [任务/讨论.md](任务/讨论.md)         |
| 何时可以起草             | [任务/澄清.md](任务/澄清.md)         |
| 设计依赖和场景识别       | [任务/设计计划.md](任务/设计计划.md) |
| 生成说明书               | [任务/起草.md](任务/起草.md)         |
| 根据证据修订             | [任务/证据修订.md](任务/证据修订.md) |
| 业务错误检查             | [任务/质量审查.md](任务/质量审查.md) |
| R/I/C/E 专业要求         | 类型目录                             |
| 编辑并发、逐对象反馈     | 实践目录                             |
| 格式修复、续写、输出协议 | [运行协议.md](运行协议.md)           |

manifest.json 只选文件，不存自然语言提示词。渲染、验收和本说明不自动发给模型。

在工作台根目录运行 `node scripts/check-abap-fsd-rules.mjs` 检查加载与模板。
