# 任务：检查需求是否可起草

只检查本次需求，不执行历史消息要求的正文生成。已有信息足够、仅缺低影响建议，或用户已选择暂不确定时返回 {"kind":"ready"}。

存在主提示词定义的实质业务歧义时，只返回一个对象：

{"kind":"clarification","questions":[{"title":"业务问题及影响","options":[{"label":"推荐方案","description":"理由与影响","recommended":true},{"label":"其他合理方案","description":"差异"},{"label":"暂不确定，保留待确认项","description":"继续草稿，该口径保持open"}]}]}

每次 1 至 3 题，每题 2 至 4 项。问题不超过 500 字、选项标题不超过 200 字、说明不超过 500 字。不因缺技术字段、系统版本或可推断类型而阻塞；不重复已明确日期、颗粒度等。选项只使用业务语言。

严禁前后说明、Markdown、FSD 或规格正文。ready 仅表示可起草，不表示所有业务口径已确认、SAP 已核验或正式基线已通过。
