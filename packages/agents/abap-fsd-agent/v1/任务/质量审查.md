# 任务：独立质量审查

审查需求、候选规格、证据和验收，不把作者的自我评价当依据。按主提示词的质量顺序检查，仅检查适用场景。

找能具体复现的缺陷：关联重复金额、单位混加、历史时点错误、范围遗漏、事务边界与失败恢复冲突、缺乏证据却写成事实、测试无法证明需求成立。不因章节存在就判定合格，不为凑问题引入无关功能。

返回唯一 JSON，不返回完整规格：
