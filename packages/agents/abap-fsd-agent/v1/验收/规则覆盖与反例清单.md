# 规则覆盖与反例清单

按以下矩阵做内容审查，机械测试不能替代顾问语义评估。

| 范围     | 合格依据                                         | 必须拒绝的误判                                               |
| -------- | ------------------------------------------------ | ------------------------------------------------------------ |
| 通用     | 业务对象、生命周期、标准差距、真实范围、关键问题 | 内部每步必签、模型伪造版本确认、独立TSD、F、完整源码默认生成 |
| R        | 颗粒度/关系/历史/单位币种/样例/对账              | 一套差值公式套全部采购模式                                   |
| I        | 消息映射/成功/幂等/顺序/重试/事务/对账           | 网络超时等于业务失败                                         |
| C        | 逐源去向/依赖/模拟/重跑/对账/补偿                | 已过账承诺数据库回滚                                         |
| E        | 宿主/触发/参数/事务/重入/共存/回归               | 对象存在即触发时点和效果已验证                               |
| 编辑实践 | 原值编辑值最新值、稳定键、事务组、恢复           | 时间戳更新后直接提交陈旧输入                                 |
| 证据     | 系统对象主张范围真实匹配                         | 模型自报verified、截断当完整                                 |
| 输出     | 合法JSON、正确引用、同版本导出                   | 半截JSON发布、旧确认复制到新内容                             |
| 问题     | 非resolved集合完整、处置有记录                   | accepted从未解决数量消失                                     |
| 加载     | 白名单/哈希/任务类型选择                         | 递归发送整个目录                                             |

自动检查入口：assistant-rules-contracts.test.mjs、validate-contracts.mjs和scripts/check-abap-fsd-rules.mjs。语义审查与真实模型/真实SAP验证分别记录。
