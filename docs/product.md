# 产品说明：SAP 智能交付工作台

> 状态：现行 · 最后更新：2026-10-31。本文只写已确认、已上线的现状；规划中的内容见[路线图](roadmap.md)。

## 1. 定位

实施方团队内部使用的 SAP 交付生产工具：顾问用它完成设计（FSD）、开发、测试等交付工作，降低实施成本。平台、智能体、提示词和评测资产归实施方所有；交给客户的是产出物（FSD、代码、测试资料、开发清单导出），不是工具本身。

边界（详见[平台定位方向决策](decisions/2026-10-17-platform-positioning-decision.md)）：

- 不做客户的项目管理系统：需求池、RAID、变更、缺陷、传输请求以客户指定的工具为准。
- 只部署在实施方环境，不做客户内网部署；只连开发与测试系统，不连生产。
- 项目数据无限期保留，项目结束后人工归档。

## 2. 用户

实施方的项目成员。权限按“权限点 → 角色 → 职位”组织，企业级与项目级分开，项目内还可限定模块与“仅本人负责”（[权限设计](modules/access.md)第 2 节）。预置角色：

| 层级   | 角色                                                                 |
| ------ | -------------------------------------------------------------------- |
| 决策层 | 交付总监、PMO（跨项目）                                              |
| 项目   | 项目经理、方案架构师                                                 |
| 模块   | 开发组长、业务顾问、开发顾问、分包开发、测试人员、Basis 顾问、观察者 |
| 平台   | 超级管理员、用户管理员、权限管理员、项目管理员、平台配置员、审计员   |

客户方人员目前不是平台用户。

## 4. 技术

Vue 3 + Fastify + PostgreSQL，npm workspaces；智能体共用 `agent-core`；SAP 通过内置 ADT MCP 访问，只读（测试数据创建是唯一例外）。目录与依赖见[目录与依赖契约](architecture/repository-contract.md)，运行见根目录 [README](../README.md)。
