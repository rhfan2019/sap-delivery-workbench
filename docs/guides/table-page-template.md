## 按钮按操作范围放置

| 类别     | 判断           | 位置与样式                                                                                      | 开发清单中的按钮                                                     |
| -------- | -------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 页面操作 | 不依赖选中数据 | 标题区右侧；主要任务用实心主色，其余为次要按钮或收进下拉菜单                                    | 新建开发项（主）、导入 / 导出（下拉）、清单设置                      |
| 批量操作 | 作用于勾选的行 | 勾选后替换筛选栏，显示“已选 N 项”；未勾选时不出现                                               | 批量修改、批量复制、导出选中项、删除、取消选择                       |
| 单条操作 | 作用于某一行   | 行右端的悬浮操作条：悬停、键盘聚焦、勾选或在抽屉中打开时出现，触屏常显；高频为图标，其余收进“⋯” | 图标：设计、开发；更多：顾问测试、IT/用户测试、查看/编辑、复制、删除 |
| 危险操作 | 删除、停用等   | 二次确认，确认文字写明对象，如“确定删除开发项 00031《……》吗？”                                  | 单条删除、批量删除、删除标签                                         |

导出按钮写明范围：“导出筛选结果（N 项）”属于页面级（导入 / 导出菜单），“导出选中项”属于批量操作。导入是“选择文件 → 服务端检查并预览 → 确认写入”三步，任何一行有错误就不写入。

## 行内编辑约定

- 只用于短字段的快速修改：单选、人员、日期、完成百分比、人天、短文本，以及同类自定义列。富文本、开发对象、标签在抽屉中编辑。
- 可编辑单元格悬停时显示浅底色和铅笔图标；不可编辑的单元格没有悬停效果。单击（或键盘 Enter / F2）进入编辑。
- 下拉选择改完即保存；输入框按 Enter 或离开单元格时保存，Esc 取消。保存中显示加载图标并锁定控件。
- 保存失败时错误显示在该单元格内，保留用户输入，可直接修改后重试。成功后用服务器返回的行替换旧行；请求带 `rowVersion`，冲突返回 409。

## 详情抽屉

- 右侧抽屉，与“大模型(LLM)”页面抽屉同一布局：头部（编号 · 模块 · 类型、标题、四个阶段状态，右侧“设计”按钮和关闭），可滚动正文，底部固定操作栏。
- 不分页签：正文按字段分组依次显示，顶部是分组跳转条；附件与最近活动放在最后。
- 头部按钮：设计、开发，以及“⋯”（顾问测试、IT/用户测试）；阶段状态只显示状态，不显示百分比。
- 打开时为查看模式，底部“关闭 / 编辑”；编辑模式底部“取消 / 保存”，只提交改动过的字段。删除在底部左侧。
- 点击另一行切换抽屉内容；点击页面其他位置关闭抽屉（有未保存修改时先确认）。
- 有未保存修改时，关闭抽屉、切换开发项、离开页面都会先确认。

## 新页面接入

1. 声明具有稳定 `id` 的业务行类型，以及 `WorkbenchColumn[]`（可带 `group` 显示表头分组色条）。业务字段通过 `cell` 插槽呈现，不在通用组件中调用业务 API。
2. 提供 `rows`（当前页）、`checked`（勾选 ID）、`currentId`（抽屉中的对象，独立于勾选集）、`loading`、`disabled`。
3. 绑定 `sortField`/`sortOrder` 并处理 `sort` 事件。先对完整筛选结果排序，再切页。
4. 监听 `columns-change` 获取个人配置中的字段顺序（导出按此顺序）。用 `ref.openColumns()` 打开列设置。
5. `storageKey` 至少包含页面配置版本、组织 ID、用户 ID（开发清单还含项目 ID，因为自定义列按项目不同）。列配置变化（如新增自定义列）时组件会合并新列。
6. 通过 `mobile-row` 插槽定义窄容器布局；组件父容器必须提供明确高度。

## 状态与安全约定

- 改变筛选、范围、排序或每页条数时清空勾选。抽屉对象不等于批量选择对象。
- 批量修改、复制、删除走一个后端接口，在同一事务内全部成功或全部失败；不再逐条调用单行接口。
- 只读（已归档）项目仍可查看、筛选和导出，但不能新建、编辑、导入或删除。
- 状态同时用文字和颜色表达；计划完成日期已过但未完成的阶段显示“逾期”提醒，不自动改数据。

## 导出与性能边界

Excel 由后端生成（`exceljs`），导出列按个人列设置的顺序，富文本导出为纯文本。重新导入时，若富文本单元格内容未改，保留原有格式。

当前接口一次返回项目清单，前端进行筛选、排序与分页，**尚非服务端分页**；每页 20/50/100 条。数据规模增长时应先扩展后端查询契约，再接入服务端分页。
