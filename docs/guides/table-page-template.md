## 页面结构

紧凑标题 → 可折叠筛选栏 → 生效条件标签 → 工作范围页签 → 表格工具栏 → 表格 → 分页。

新增是主要操作。删除根据权限与勾选状态启用。复制仅预留，禁用并提供说明。
设计、开发跳转到工作区，因此使用 RouterLink；修改或删除数据的动作使用 button。
查看编号打开当前页详情，不改变多选集。

## 新页面接入

1. 声明具有稳定 `id` 的业务行类型，以及 `WorkbenchColumn[]`。业务字段通过 `cell` 插槽呈现，不在通用组件中调用业务 API。
2. 提供 `rows`（当前页）、`checked`（当前页 ID 数组）、`currentId`（详情对象，独立于勾选集）、`loading`、`disabled`。
3. 绑定 `sortField`/`sortOrder` 并处理 `sort` 事件。先对完整筛选结果排序，再切页；不能只排序当前页。
4. 监听 `columns-change` 获取个人配置中的字段顺序。使用 `ref.openColumns()` 打开原生模态列设置窗口。
5. `storageKey` 至少包含页面配置版本、组织 ID、用户 ID；字段发生不兼容调整时升级版本。列显隐、顺序、宽度保存在 localStorage，业务筛选在页面层独立存储。
6. 通过 `mobile-row` 插槽定义窄容器布局。组件按自身宽度而非整个窗口决定布局，低于 600px 使用条目列表；`compactKeys` 可为分栏指定核心列。
7. 组件父容器必须提供明确高度，桌面避免重复纵向滚动。手机使用独立的有限高度条目区域。

`required` 防止隐藏核心字段；`fixed` 指定冻结位置；`hideBelow` 自动减少窄容器低优先级列。这种响应式隐藏不修改用户偏好。开发清单在容器低于 1280px 时临时隐藏“类型”和“业务顾问”；完整字段仍可在详情查看。

## 状态与安全约定

- 勾选仅限当前页；改变筛选、角色范围、排序、页码或每页条数时清空，并显示反馈。详情对象不等于批量选择对象。
- 编辑保存前使用独立草稿；明确保存/取消。请求失败保留草稿，成功后用服务器返回的行替换旧行。PATCH/DELETE 继续传递 `rowVersion`。
- 离开页面、切换详情、刷新、创建或删除前沿用未保存确认。保存期间禁用范围改变和删除，避免请求与 UI 对象错位。
- 批量删除是对现有单行接口依次调用，不是原子事务。逐项移除成功项，失败项保留，显示失败编号与原因，允许重试。后端权限和引用检查仍是最终依据。
- 只读项目仍可查看、筛选和导出，但不能创建、编辑或删除。
- 列设置使用原生 dialog，支持 Escape、焦点约束及关闭后焦点恢复；排序和选择使用原生可聚焦控件。
- 选中行、当前详情、悬停和键盘焦点分别表现；状态同时用文字和颜色表达。阻塞原因不会替换业务阶段。

## 导出与性能边界

CSV 导出当前筛选与排序后的全部已获取结果，按个人列配置的顺序输出；响应式临时隐藏的字段仍保留。转义 CSV 内容并处理公式注入前缀。

当前接口一次返回项目清单，前端进行筛选、排序与分页，**尚非服务端分页**。虚拟滚动没有开启；每页 20/50/100 条。数据规模增长时应先扩展后端查询契约，然后接入分页，不能把虚拟滚动当成减少后端数据传输的方案。

当前依赖锁定 `vxe-table@4.22.3`、`vxe-pc-ui@4.18.21`。通用表格使用自定义 loading 插槽，不依赖全局注册 UI loading 组件；页面路由按需加载。生产构建仍存在大 chunk 提示，后续性能预算应以真实首屏测量决定是否进一步拆分。
