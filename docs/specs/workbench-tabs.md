# 工作台多标签页

状态：第一期（工作台菜单页面）已实施（`53eb9d5`），用户 2026-10-29 确认；开发项多标签暂缓（[FEAT-007](../plans/backlog.md)），项目跟随标签另行实施（[FEAT-006](../plans/backlog.md)）。界面取值见 [DESIGN.md](DESIGN.md) 第 4.1 节“标签栏”。

像浏览器一样，同时打开工作台的多个页面，切换时不重新加载。

## 1. 范围

| 页面                                                                 | 第一期                                                                                                                                       |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 外壳内的菜单页面：工作台、开发管理、知识与资产、设置                 | 在标签内打开、切换时保留                                                                                                                     |
| 菜单页面的详情页（用户、角色、审计运行与会话）                       | 同上，标签取所属菜单项的名称                                                                                                                 |
| 开发项记录页（`…/development-items/:itemId/design`、`/development`） | 在当前标签内打开，不保留、不提供“在新标签页打开”（FEAT-007）；记录页照旧收起二级菜单，标签栏随内容面板左移，记录页的菜单处理随 FEAT-007 决定 |
| 登录、修改密码、组件展示页                                           | 不在外壳内，没有标签                                                                                                                         |

## 2. 模型

- **外壳是导航器，标签是页面。** 图标栏、二级菜单、标签栏全局唯一；每个标签是一个地址加它自己的页面实例。
- 浏览器地址栏始终是当前标签的地址；浏览器前进、后退作用于当前标签。
- 二级菜单、页头（位置与主操作）跟随当前标签：切到“项目成员”标签，菜单变成设置菜单并选中“成员”。
- **一个菜单项一个标签**（用户 2026-10-29 确认）：从菜单入口打开页面时，该菜单项已有标签就切过去，没有才新开。菜单项的标签指页面属于该菜单项的标签（详情页属于所属列表，如用户详情属于“用户”），优先取地址正好是该菜单项的标签。只有明确要求新开（Ctrl / 中键、右键“在新标签页打开”、“+”）时，同一页面才会出现在多个标签里。

## 3. 打开

| 操作                                                                                                           | 结果                                                         |
| -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 菜单入口：点菜单项、图标栏模块（含左上角标志）、命令面板（Ctrl+K）里的页面、设置搜索回车、头像菜单的“个人资料” | 该菜单项已有标签则切过去，否则在当前标签右侧新开标签并切过去 |
| 页面里的链接（面包屑、开发清单进入设计 / 开发助手、详情链接等）                                                | 在当前标签内打开                                             |
| Ctrl / ⌘ + 点击、中键点击菜单项或图标栏                                                                        | 总是在当前标签右侧新开标签并切过去（即使已有该菜单项的标签） |
| 右键菜单项或图标栏                                                                                             | 菜单：在新标签页打开、在新窗口打开、复制链接                 |
| 标签栏末尾的“+”                                                                                                | 新开标签，打开工作台首页                                     |
| 从地址栏、书签或别处的链接进入                                                                                 | 已有同地址的标签则切过去，否则新开标签                       |

## 4. 切换与保留

- 切换标签不重新加载：页面实例保留（最多 10 个，超出时最久未用的先释放，再切回时重新加载）；内容区的滚动位置按标签记住。
- 切换标签不触发“未保存的修改”确认，因为页面并未离开。
- 只有当前标签的页面响应快捷键；开发清单打开详情时为记录让出空间（自动收起二级菜单），只对当前标签生效。
- 开发项记录页不保留：离开记录页即释放，与现在一致。
- 标签切换不设快捷键：Ctrl+Tab、Ctrl+W 等由浏览器占用。

## 5. 关闭

- 标签上的 ×、中键点击标签；右键标签：关闭、关闭其他标签、关闭右侧标签。
- 关闭当前标签后切到右侧标签，没有则左侧；最后一个标签关闭后打开工作台首页，始终保留一个标签。
- 页面有未保存的修改时（如开发清单详情抽屉、模型设置），先切到该标签再询问；选择取消则不关闭。

## 6. 记住

- 打开的标签与当前标签按用户记在浏览器本地（`localStorage` 的 `workbench-tabs:<用户编号>`），刷新、重新登录后恢复；不同用户互不影响。与菜单宽度一样属于个人便利，不存服务器；浏览器拒绝存储时只在本页有效。
- 恢复时只恢复地址，页面在第一次切到该标签时才加载。

## 7. 标题与图标

- 取菜单项的名称与图标，详情页取所属菜单项（如“用户”）；设置总览为“设置”；开发项记录页为“设计助手”“开发助手”。
- 标签宽度在最小与最大宽度之间伸缩，标题超长省略，悬停显示完整标题；标签多到最小宽度也放不下时，标签栏横向滚动，当前标签始终滚入可见区。

## 8. 项目与权限

- **第一期项目仍是全局的**：在任一标签的页头切换项目，所有作用于项目的标签一起切换，与现在一致。项目跟随标签（写进地址，各标签独立）见 FEAT-006。
- 标签只是前端导航，不新增权限点；恢复的标签照常经路由与接口校验，无权限的页面按现有方式显示。
