# 设计规范

本文件是全站界面的唯一规范，版本 2.0 整体替换 1.x（中性白 + 海军蓝、三套可换主题）。新外观参照 Plain：
**结构清楚、颜色克制、反馈一致**。实现时只用这里的令牌（`apps/web/src/assets/theme.css` 中的 CSS 变量），不写新的取值；需要新令牌时先改本文件。

## 1. 原则

1. **几块白板浮在浅灰底上。** 页面底色 `neutral.bg-2`；内容在白色圆角面板里，面板四周留 8px 缝，用 `card` 阴影，不用粗边框分区。
2. **颜色只表达语义。** 界面几乎全是灰阶；色相只出现在标签、色带、图标与状态上，每种用途有固定色相（第 2.2 节）。主按钮是墨色，不是彩色。
3. **标题不加粗。** 页面标题 24px、字重 regular；层级靠字号和位置。正文 14px。
4. **每个可交互元素都有短促、一致的反馈。** 悬停 75ms 换底色，弹层 150ms 位移 4px 淡入；不做弹跳、上浮、发光。
5. **键盘优先。** 主要操作都有快捷键，并在按钮、菜单里用 `kbd` 标出来。
6. **企业密度。** 表格行高 44px、菜单项 32px，控件小而准；留白靠面板缝与分组间距，不靠放大控件。

## 2. 颜色

### 2.1 角色

每种色相（neutral、blue、green、purple、red、yellow）都有同一组角色，CSS 变量为 `--<色相>-<角色>`：

| 角色                  | 用途                                       |
| --------------------- | ------------------------------------------ |
| `bg-1` / `bg-2`       | 整块浅底：页面、色带、备注块               |
| `fill-1/2/3`          | 标签底、按钮底、悬停与选中（数字越大越深） |
| `border-1/2/3`        | 描边：分隔、输入框、强调描边               |
| `text-1` / `text-2`   | 在浅底上的深色字 / 强调字（链接、标签字）  |
| `icon-1` / `icon-2`   | 图标                                       |
| `solid-1` / `solid-2` | 实心按钮、徽标、进度（2 为悬停或按下）     |

### 2.2 语义（固定，不挪用）

| 用途                         | 取色                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| 页面底 / 面板                | `neutral.bg-2` / `neutral.bg-1`                              |
| 正文 / 次要 / 辅助           | `neutral.text-1` / `neutral.text-2` / `neutral.text-3`       |
| 分隔线 / 输入框边 / 强调边   | `neutral.border-1` / `neutral.border-2` / `neutral.border-3` |
| 悬停 / 选中                  | `neutral.fill-1` / `neutral.fill-2`                          |
| 主按钮                       | `neutral.solid-1` 底、白字，悬停 `neutral.solid-2`           |
| 链接、焦点环、正在进行       | blue（链接 `text-2`，焦点环 2px `solid-1`）                  |
| 已完成、AI 建议与 AI 图标    | green                                                        |
| 内部备注、测试数据、需要留意 | yellow                                                       |
| 等待用户决定、状态事件色带   | blue `fill-1` 色带                                           |
| 延误、错误、删除             | red                                                          |
| 自定义类别（标签、模板类别） | purple 及其他色相，由用户选择                                |

阶段状态：未开始 neutral、进行中 blue、已完成 green、已延误 red、已取消 neutral（删除线）。

### 2.2.1 身份色（2026-10-17 增补）

Plain 不“素”，靠的不是装饰，而是每一行、每一条消息都带着几处**身份色**：人有自己颜色的头像，类别有图标，优先级有记号。身份色只标识“是谁 / 是哪一类”，固定不变，与第 2.2 节的状态语义互不挪用。实现集中在 `components/base/identity.ts`，页面不各自取色。

| 对象     | 呈现                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 人员     | 方形头像（首字、`solid-1` 底）+ 名字；色相由名字散列到 blue / green / purple / red / yellow，同一人永远同色；未分配显示虚线空头像 |
| SAP 模块 | 标签（`fill-1` 底、`text-1` 字）：FI/CO 系 green、SD blue、MM purple、PP yellow，其余按名称散列；同一模块全站同色                 |
| 开发类型 | 彩色小图标 + 文字：报表 blue、功能 purple、接口 green、增强 yellow                                                                |
| 优先级   | 记号 + 文字：高为 red 圆形感叹号、中为 yellow 信号格、低为 neutral 信号格                                                         |
| 助手     | green `solid-1` 方形头像加闪光图标；助手给出的可点建议是 green `fill-1` 小按钮（`text-1` 字）                                     |

开发清单的行是两行：第一行开发名称（14px semibold），第二行业务功能点摘要（12px `text-2`，单行截断）；行高 `--control-table-row-double`（56）。

助手页时间线：用户消息左侧是用户头像，助手回复左侧是助手头像；等待用户回答的问题上方是 blue 色带“需要你决定”；运行结束后，成果下面给出 green 建议按钮（打开成果、继续追问的常用说法）。

### 2.3 深色

深色模式跟随系统（`prefers-color-scheme`），不提供手动切换。深色值同样来自 Plain：neutral 依次为 bg `#121113 / #1A191B`，fill `#232225 / #2B292D / #323035`，border `#2B292D / #323035 / #49474E`，text `#EEEEF0 / #B5B2BC / #7C7A85`；各色相取对应的深色角色值（实现见 theme.css 的 `@media (prefers-color-scheme: dark)`）。主按钮在深色下为浅底深字。

## 3. 字体

- 无衬线：Inter 可变字体（随项目部署，`@fontsource-variable/inter`）加苹方 / 微软雅黑；代码与 SAP 对象名用等宽字体。
- 字号只用 7 级：11（快捷键）、12（表头、标签、说明）、14（界面与正文默认）、16（文档阅读正文）、20（面板标题）、24（页面标题）、32（登录页等少数场合）。
- 字重只用 regular 400 / medium 475 / semibold 550。页面标题用 regular；菜单选中项、表格主列、属性面板标签用 semibold。

- **图标栏**（56px）：模块入口为 32×32 图标按钮（圆角 6），选中 `neutral.fill-2` 底；悬停时显示深色提示。顺序：工作台、开发管理、知识与资产、设置；底部为通知（铃铛，向右弹出通知列表；提醒上线前显示空状态说明，届时铃铛加未读角标）、搜索与头像菜单。二级菜单收起时点模块图标，跳转的同时展开菜单。
- **二级菜单**（248px）：顶部是企业名称与平台名称（身份，不可点击）和收起按钮；下面是当前模块的菜单（设置模块另有搜索）。菜单项高 32、圆角 6，左图标右计数；未选中为 `text-2`，选中为 `fill-2` 底、`text-1`、semibold。分组标题 12px、`text-1`、semibold，上方 `border-1` 细线，右侧折叠箭头，组内菜单缩进 8px（第 4.2 节）。
- **页头**（2026-10-18 用户确认）：内容面板顶部一行，高 48（`--layout-record-bar`）、底部 `border-1` 细线，所有页面都有（记录页用自己的 48px 顶栏代替）。左侧是位置：作用于当前项目的页面（工作台、开发管理、知识与资产、设置中的“项目”分组）以项目切换器开头，后接模块与页面，如“虚拟项目 ▾ › 开发管理 › 开发清单”；个人与企业设置不出现项目切换器，如“设置 › 企业 › 用户”。项目切换器弹层可搜索（名称、简称、编号、客户，回车选第一项），按客户分组，已归档项目不显示，底部为“设为默认项目”。二级菜单收起时，展开按钮在页头最左侧。页头右侧是页面的主操作（页面用 `<Teleport defer to="#page-actions">` 放入），如开发清单的“导入 / 导出”“新建开发项”；页面本身不再有大标题行（标题只给读屏，`sr-only`）。
- **标签栏**（2026-10-29 用户确认，行为见 [工作台多标签页](workbench-tabs.md)）：内容面板上方一行，高 36（`--layout-tab-bar`，低屏 32），在页面底色上，取代内容面板的上方 8px 缝。标签高 28（`--control-tab`）、上圆角 8、内边距 0/8，左侧 14px 菜单图标、12px 标题（超长省略）、右侧 16px 关闭按钮；宽度在 120–200 间伸缩（`--layout-tab-min` / `--layout-tab-max`），放不下时横向滚动（不显示滚动条）。未选中为 `text-2`、悬停 `fill-1` 底；当前标签为白底（`--panel`）、`text-1`，与下方内容面板连成一体；标签之间不画分隔线。点菜单项、图标栏模块打开页面：该菜单项已有标签就切过去，没有就新开一个。末尾为“+”图标按钮（新开工作台首页）。右键标签弹出菜单：关闭、关闭其他标签、关闭右侧标签；右键菜单项或图标栏弹出：在新标签页打开、在新窗口打开、复制链接。窄屏照常显示、横向滚动。
- **内容面板**：白底、圆角 12、`card` 阴影。只有页头以下部分滚动；内边距为 `--body-pad-y` / `--body-pad-x`（默认 24 / 32），贴边的区域（如清单的列表区）按这两个值反向外扩。
- **低屏幕**（2026-10-18 用户确认，可视高度 ≤ 820px，即 1920×1080 笔记本 125–150% 缩放或 1366×768）：页头与记录页顶栏降为 40（`--layout-record-bar`），标签栏降为 32（`--layout-tab-bar`），表格行高 36、两行行高 48，内容面板内边距 16 / 24，开发项详情的分组页签、分组与底栏随之收紧。
- **自动收起菜单**：宽度 < 1440px 且清单旁打开了记录（开发项详情）时，二级菜单自动收起，关闭记录后恢复；期间手动展开会一直保持到记录关闭。页面通过 `services/shell.ts` 的 `detailOpen` 告知外壳。
- **双面板**：打开一条记录时，二级菜单收起，列表收窄为 400px 的面板，记录在右侧大面板中打开（第 6.3 节）。
- **可拖动宽度**：二级菜单（200–400）与双面板中的列表（380–760）在右边缘拖动或用 ←/→ 调整宽度，按人记住（`BaseResizeHandle`）。列表页只让表格与详情面板各自滚动，内容面板本身不滚动；表格按去掉纵向滚动条后的宽度排列，不出现横向滚动条。
- **开发项详情面板**（2026-10-18 起）：头部一行，依次为 24px 类型色块图标、编号 / 模块标签、类型、16px 标题（超长省略）与“设计 / 开发”按钮（点击即显示加载并禁用，打开面板时预取助手页面代码）；下面是随滚动高亮的分组页签，各阶段分组的页签后带该阶段状态（未开始不显示），负责人与计划日期在分组内容中；再下面是各分组。切换开发项时面板不重建、不重放进场动画，回到顶部。
  - **分组**（2026-10-29 用户确认）：每组是 16px 分组标题加一张卡片（白底、`border-1` 细线、圆角 12、内边距 16），组间距 20。卡片内的属性一律“标签在上、值在下”：标签 12px `text-3`，值 14px；短属性排成网格，抽屉内容宽 ≥ 560 时四列、≥ 360 时两列、更窄一列（容器查询）；长文本（业务功能点、备注、长文本自定义列）、开发对象和标签占整行，与网格之间用细线隔开。
  - **阅读时**：编号、模块、类型、名称只在头部显示；阶段分组的状态标签跟在分组标题后（未开始显示灰色“未开始”），卡片第一行是负责人（头像、姓名、角色），下面依次是“计划”（开始 → 完成合成一格，占两格）、实际完成、人天、完成度（带进度条）；空字段不逐行显示，合成一行“某某、某某未填写”；未开始且没有填写任何字段的阶段，卡片缩成一行提示。长文本默认显示三行，超出时可“展开”。
  - **编辑与新建时**：卡片和网格不变，每个值换成输入框，阅读时省略的字段全部回到原位：名称（占两格）、模块、类型在基本信息第一行；负责人（占两格）、状态、完成百分比在阶段第一行；计划开始与计划完成是并排的两个日期框，占两格。必填项标签后带红色星号。切换阅读与编辑时，当前分组保持在原来的位置。
- **窄屏**（< 760px）：图标栏保留，二级菜单收进抽屉；双面板改为单面板加返回按钮。

### 4.2 设置的菜单分组

2026-10-17 起按[项目主数据、权限与设置菜单设计](project-access-admin.md)第 4 节：二级菜单顶部为“搜索设置”与“概览”，下面是个人（个人资料、我的 SAP 凭据、通知）· 项目（基本信息、计划与健康、团队与干系人、成员与权限、SAP 系统、规模与商务、开发清单设置、模型与智能体）· 企业（企业资料、客户、项目、项目字段、用户、职位、角色与权限、安全策略）· 智能体（大模型、提示词与框架）· 审计与运维（审计日志、SAP 系统一览、连接诊断、运行记录）。菜单全量列出，未实现的页面在菜单右侧标“规划中”，打开后是统一的“规划中”页面；用户没有查看权限的页面不显示，没有可见项的分组整组隐藏。项目分组的标题只写“项目”，所作用的项目看页头。分组可折叠：默认展开个人与项目，收起企业、智能体、审计与运维；打开某页时自动展开其分组，搜索时全部展开；折叠状态按浏览器记住。

## 6. 页面模式

### 6.1 列表页（开发清单等）

页面标题与主按钮在页头（第 4.1 节）；内容区第一行依次是视图页签、搜索框（弹性宽度 180–420）、“筛选 F”“显示 V”与刷新，窄时换行；然后是表格。批量操作出现在选中行之后的浮动操作条里。

### 6.2 设置（总览与子页面）

`/settings`，图标栏的“设置”打开这里。居中一栏，最大宽 760；分组标题 16px 加一句说明，下面两列卡片（图标方块 + 标题 + 一句说明，规划中的页面带“规划中”标签），分组之间用 `border-1` 细线分隔。

子页面统一由 `features/settings/SettingsPage.vue` 排版：可选的“← 返回”、24px 标题与一句说明、右侧操作；表单页最大宽 760，列表页（`wide`）最大宽 1120。内容是 `SettingsCard`：带标题与一句说明的白色卡片，每个设置项为 `SettingsField`（左侧名称与说明、右侧控件），卡片底部右下角的“保存”只保存本卡片，没有改动时不可点。列表页（2026-10-29 用户确认，以“大模型”为准）为“一行概要（如当前默认）→ 工具行（搜索框、筛选下拉、右侧主按钮）→ 设置列表表格（第 5 节）→ 表格下方说明”，新增与编辑在右侧抽屉（第 5 节）里进行，不用对话框；对话框只用于确认、登录 SAP、复制等一次性的小操作。页面用 `SettingsPage` 的 `list`（最大宽 1600，与大模型一致）与 `drawer`（抽屉打开时让出宽度）；表格、抽屉、⋯ 菜单与离开前询问由 `features/settings` 的 `useDrawerLeave.ts`、`SettingsDrawer.vue`、`SettingsRowMenu.vue` 与 `settings.css` 的 `.s-table*`、`.s-drawer*` 提供，页面不另写同类样式。设置区的列表全部按此实现（第 12 批）：大模型、成员与权限、SAP 系统、用户、角色与权限、职位、客户、项目、我的 SAP 凭据、SAP 系统一览；用户、角色、项目点行打开抽屉（用户、角色用宽抽屉），原用户、角色详情页删除；只读的列表（SAP 系统一览）没有抽屉。团队与干系人、计划与健康这类以设置卡片为主的页面，卡片照旧，其中的列表（客户方联系人、里程碑）用同样的表格，前面是 16px 标题与一句说明（`.s-list-section`），新增、编辑与更新健康度在抽屉里。原生表单控件统一用 `settings/settings.css` 的 `.s-input`、`.s-select`、`.s-textarea`、`.s-check`。尚未开放的页面显示“规划中”。

### 6.3 记录页（开发项与设计 / 开发助手）

开发项的设计助手与开发助手是同一个记录页的两个页签，地址仍为 `…/development-items/:itemId/design` 与 `…/development`（第 4 批决定保留地址，旧链接不需要跳转）。

- **顶栏**（48px，`--layout-record-bar`）：返回开发清单、编号标签与标题、“设计 / 开发”分段页签、当前对话（点开为对话列表，可切换与改名）；右侧为资料、新对话、开发项信息开关、成果面板开关、⋯。窄屏分两行：标题与操作一行，页签与对话一行。
- **时间线**（左，阅读宽度 760）：
  - 用户消息为 `neutral.fill-1` 消息块（圆角 8、14/24）；助手回复为正文排版，不套块。
  - 运行步骤、实时状态、待决定问题、测试数据授权、成果卡片沿用原有组件与流式机制，只换外观。
- **输入框**：助手的主要工作是对话，输入框常驻底部，是白底、圆角 12、`floating` 阴影的浮动卡片，聚焦时 1px `focus` 描边；R 聚焦输入框，U 上传资料，Esc 停止生成。
- **成果面板**（中，可拖动宽度）：功能说明书或开发方案与代码，一行工具栏加可拖动宽度的目录。
- **开发项信息**（右，384px，`--layout-details`）：基本信息、开发对象、业务功能点，各分组可折叠；开关状态按人记住。窄屏时与对话、成果面板三选一。

### 6.4 工作台首页与项目

不放横幅与装饰图形。页头为“你好，姓名”加日期，右上主按钮“打开开发清单”；下面是“常用”四张卡片（图标方块 + 标题 + 一句说明），再下面左右两栏：我的项目（行高 44，项目名、客户 · 编号、状态标签）与知识与资产。我的项目页为页头、搜索框与同样的项目行；项目详情为页头（编号与状态标签）加可折叠的“项目概览”属性分组。

### 6.5 登录与修改密码

页面底色上居中一张卡片（最大宽 380、圆角 12、`card` 阴影）：品牌、20px 标题、一句说明、表单与墨色主按钮。首次登录的修改密码页同样是一张卡片；个人设置里的“账号安全”是同一表单，不套卡片。

## 7. 动效

- 只用三档时长：75ms（悬停与按下换色）、150ms（多数过渡、弹层）、300ms（对话框、折叠展开）；侧滑面板用 400ms 的 `panel` 曲线。
- 弹层朝弹出方向位移 4px 加淡入；对话框从下方 16px、缩放 0.96 进入；折叠为高度动画；加载用骨架屏（透明度呼吸，不用渐变流光）。
- 列表和面板切换只做淡入，不做依次进场。
- 系统开启“减少动态效果”时，只保留透明度变化。

## 8. 可访问性

正文对比度 ≥ 4.5:1，控件边框与图标 ≥ 3:1；所有可交互元素有可见焦点环（2px `blue.solid-1`）；不能只用颜色区分状态（标签带文字）；图标按钮有可读名称；快捷键不抢输入框里的按键。

字号、圆角用带数值的名字，避免与 1.x 的同名变量（如 `--radius-md`）混淆。1.x 的变量名已在第 7 批全部删除；样式中的 `var(--…)` 只能引用本表的令牌或页面自己声明的属性，检查器会拒绝其他名字（契约 1.16）。另有两个正式令牌：开发项标签颜色 `--tag-<颜色>-bg / -text`（按名称存储），设置列表抽屉宽度 `--layout-drawer` 与宽抽屉 `--layout-drawer-wide`。

阴影规则：带模糊的阴影只能用阴影令牌；不带模糊的描边环与细线（如 `0 0 0 2px var(--focus)`、`inset 0 -1px 0 var(--border)`）可以直接写。时长只能用时长令牌。

基础组件放 `apps/web/src/components/base/`（`Base` 前缀）；开发环境提供组件展示页 `/dev/components`（`?view=list | record | controls`），深色由系统设置切换。

## 10. 不要做

- 不新增取值；不用渐变、发光、上浮动效；不给卡片同时加粗边框和阴影；不在卡片里再套卡片。
- 不用状态色做装饰；色相按第 2.2 节的语义与第 2.2.1 节的身份色使用，页面不自行取色。
- 不复制 Plain 的标志、品牌绿、商业字体与文案。
