## 4. 手工测试清单

每个账号登录后，先看设置菜单与页头，再在开发清单上操作。

**模块组长**（以 sheng.hu 为例，其他组长换成各自模块）

1. 设置菜单只有“个人”“项目”两组；项目组没有“规模与商务”“开发清单设置”“模型与智能体”。
2. 页头项目切换器里只有“虚拟测试项目”。
3. 开发清单中 SD 开发项可以行内修改，FICO / MM / PP 开发项的单元格不可修改；看不到“删除”“导入”；新建开发项时模块只能选 SD。
4. SD 开发项的“设计”可以对话；其他模块的开发项只能查看设计。“开发”只能查看。
5. 基本信息、计划与健康、团队与干系人只读；成员与权限只能查看。

**项目经理**（huihai.huang）

1. 项目组可见“规模与商务”，能修改合同与人天。
2. 可修改基本信息、阶段与里程碑、登记健康度、维护团队；可添加成员、分配角色（含模块范围与有效期）。
3. 开发清单可修改、删除、导入任意模块；“设计”“开发”只能查看。
4. 可登记与维护 SAP 系统。

**开发组长**（fanruihui）

1. 开发清单可修改、删除、导入任意模块；“开发”可以对话与定稿，“设计”只能查看。
2. 可维护 SAP 系统；基本信息、团队、成员只读；看不到“规模与商务”，客户联系人的电话与邮箱被隐去。

**越权验证**

- 组长新建开发项：模块下拉只有本人负责的模块；绕过界面用接口新建其他模块的开发项返回 403。
- 组长把本模块的开发项改成别的模块（如 SD 改为 PP）：允许，保存后这条开发项归新模块，组长自己不能再改，也不能改回来。
- 组长把其他模块的开发项改成本模块：不允许（该开发项本就不能修改）。
- 项目经理在成员与权限中给自己改角色：应提示“不能修改自己在项目中的角色”。
- 任一账号在地址栏打开其他项目的开发项地址（`/projects/<其他项目 id>/development-items/...`）：应提示不存在或无法访问。

## 5. 恢复

测试中如需重置，管理员在“设置 → 企业 → 用户”中可停用账号、重置密码（生成临时密码，首次登录须修改），在“设置 → 项目 → 成员与权限”中调整角色。
