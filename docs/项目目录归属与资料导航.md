# 项目目录归属与资料导航

## 项目中保留什么

apps、packages、database、infra、scripts、tests、vendor为开发部署依赖；配置、README、锁文件和启动脚本保留。packages/agents/abap-fsd-agent是产品规则，不是Codex对话记录。

artifacts为项目验证证据，outputs含项目UI评审及问题清单，docs含运维说明、实施计划和部分测试依赖的规格。这些均与项目相关，不能因为由AI生成而删除。

.runtime为本地受管服务、隔离测试和项目调试目录，保持忽略；其.env、运行状态、附件和诊断脚本不能整目录删除。node_modules为依赖缓存，不是会话资料。

docs/superpowers下部分JSON示例和source-manifest被tests/fs-workspace直接引用。当前保留路径；若后续重命名为普通项目目录，应单独迁移并更新测试引用，不能只按工具名称移出。

## 非项目资料

个人助手会话记忆、Codex聊天备份、用于生成文件的一次性工作脚本、下载的参考网页，放项目外“研发辅助”，不得作为运行规则自动加载。

2026-10-04已迁出根Codex空目录、.workbuddy会话记忆及两份未被代码引用的研究网页；旧五份提纲规则迁出存档，现由分模块实质规则替代。保留哈希迁移清单，不永久删除。
