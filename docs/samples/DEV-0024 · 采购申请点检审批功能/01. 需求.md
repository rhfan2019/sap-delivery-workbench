# 需求描述：采购申请点检与审批（在线处理）

我们 MRP 每天跑出来的采购申请不少，都要一个个过去审批，数量、需求日期经常要微调，来回切界面太麻烦。给我设计一个采购申请点检的操作界面：

- 打开后显示所有还没审批的采购申请清单（只要 MRP 跑出来的那类，类型 ZR10 的），按行项目列出来：申请号、行项目、物料、物料描述、需求数量、需求日期、采购组、工厂、库存地点，再加上工厂库存和可用库存，我好判断这个量该不该批。
- 顶上的筛选条件要有：工厂（这个必填）、库存地点、MRP 控制者、采购申请号、物料、物料组、采购组、创建日期、需求日期。筛选完没数据就提示一句"没查到符合条件的采购申请"，别让我以为系统卡了。
- 数量栏和需求日期栏可以直接在清单里改，改完点"保存"就提交。要是把数量改成 0，那就说明这行不要了，别真把数量改成零，直接把这行标记删除就行。
- 保存成功以后，清单上的数据要刷新到最新，别让我看着旧数据接着操作。
- 有勾选功能，勾好行以后点"审批"按钮，把选中的申请行全部审批通过。审批用什么审批代码我不指定，单子上配的是什么就用什么，别写死。
- 双击某一行，直接跳到采购申请显示界面（ME53N），我要看单据全貌；双击其他栏位，就按这个物料的工厂跳到 MRP 清单（MD04），我要看库存供需情况。
- 我只能审批我有权限的工厂和审批代码的单子，没权限的行别让我批，提示权限不足就行。
- 审批或者保存失败的时候，把失败原因明明白白提示出来，成功的正常过，别一失败就全卡死。
