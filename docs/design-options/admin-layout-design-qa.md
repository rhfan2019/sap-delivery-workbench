## 发现与修正历史

1. P2：默认桌面宽度下客户提前变为两列、成员侧栏落到下一行，弱化所选三栏关系。将堆叠断点由 1400px 调整为 1150px。最终企业和成员截图确认恢复三卡片/三栏；更窄屏幕主动堆叠。
2. P2：成员单选框继承原登录表单 input 的全宽和 46px 高度，挤压姓名。局部限定为 15px、去掉 padding，重设行间距。重新截图 members-admin.jpg，控件与姓名已在同一行正常呈现。
3. P2：移动端页头按钮挤压说明文字、表格字段过度换行。页头改为纵向，表格设置最小宽度并限定内部横向滚动。重新截图 members-mobile.jpg，页头正常，页面主体不被宽表格撑开。
4. 独立代码审查发现项目切换到无项目客户时 loading 可能残留。空项目分支清除 loading，浏览器确认显示“先建立项目，再组织协作”。
