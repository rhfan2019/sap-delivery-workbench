## TODO-007：SAP / MCP 连接候选

| 组内编号 | 主视图                 | 适合的管理方式                           |
| -------- | ---------------------- | ---------------------------------------- |
| 1        | 连接清单与详情抽屉     | 快速定位连接并查看状态、执行身份和配置   |
| 2        | 系统环境树与能力工作区 | 按系统/DEV/QAS/PRD 管理能力和项目范围    |
| 3        | 分步接入向导           | 逐步配置系统、服务身份、授权，再验证启用 |

## TODO-008：大模型配置候选

| 组内编号 | 主视图                 | 适合的管理方式                      |
| -------- | ---------------------- | ----------------------------------- |
| 1        | 提供方目录与接入详情   | 先管理提供方、凭据引用、模型和范围  |
| 2        | 任务矩阵与配置面板     | 按 FS、TS、代码、问答、解析分配模型 |
| 3        | 配置编辑与试运行工作台 | 对比生效版本与草稿，试运行后启用    |

共同功能基线：提供方、入口、模型标识、凭据引用、连接测试；任务配置、组织/项目范围、允许输入的数据范围、上下文策略、超时与并发。参数与工具能力以提供方验证为准。用量页承载调用量、成本、预算、失败率和延迟；首屏不堆砌未产生的指标。备用模型必须遵守同样的数据授权，不自动向未授权提供方转发。配置需区分已生效版本和草稿，可试运行、启用、回退；图中的“启用”状态不表示未经验证的草稿已经生效。
