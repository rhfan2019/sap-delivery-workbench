# 视觉方向决策：暖亮浮动面板

> 2026-11-01 定稿。状态：**已确认**。用户评估现有界面（Plain 风格加便当格首页）只有 6 分，“离眼前一亮还有很大距离”，要求重定视觉方向。本文记录讨论结论；规则写进[设计规范](../DESIGN.md) 4.0，契约变更见[目录与依赖契约](../architecture/repository-contract.md) 1.25。

## 1. 决策

> 全站换成“暖亮浮动面板”：奶白到强调色的渐变底上，浮着半透明白色大圆角卡片与胶囊形控件；颜色只有墨黑、白与一种强调色；关键数字用超大细体。强调色默认明黄，可一键换配色；不再提供深色模式。

| 问题         | 结论                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 给谁看       | 两者都要：工作台、开发概览这类展示页负责惊艳（给老板与客户演示），清单、表单这类干活页克制、保持密度                   |
| 第一眼的感受 | 原选“智能未来”；看过两版方向稿后选定暖亮版（A），AI 只在助手相关处用强调色点亮                                         |
| 参考         | Dribbble 上 Nixtio 为 Crextio 做的 HR 仪表盘：只借视觉语言（浮动面板、胶囊、超大细体数字、极少用色），不照抄布局与元素 |
| 布局         | 可以重来；导航选“浮动侧栏”（图标栏与二级菜单浮在底色上），不用顶部导航                                                 |
| 强调色       | 先用明黄，**必须支持一键换配色**                                                                                       |
| 深色模式     | 不做；换配色取代明暗切换                                                                                               |
| 人物照片     | 不用，温度靠排版与色彩                                                                                                 |

## 2. 依据

1. 原外观照 Plain 做：冷灰底、靛蓝主色、Inter，是一类 SaaS 模板的共同长相，没有辨识度；首页“图标 + 标签 + 大数字”的卡片套路也太常见。
2. 用户看了同一组真实数据做成的两版方向稿（暖亮、深色未来，各含首页与开发清单）后选择暖亮：天天用不累，演示时也够高级；深色加光效在清单页长时间看偏累。
3. 一键换配色在 1.14 做过、1.15 取消；这次只换强调色与底色的渐变，全部取值仍写在 `assets/theme.css`（`[data-theme=…]`），不恢复主题包目录与偏好接口。

## 3. 实施

按设计规范第 11 节第 18 批起分批：令牌与配色切换、外壳、工作台先做；其余页面靠令牌自动换装，逐页细修登记在[待办与问题清单](../backlog.md)。
