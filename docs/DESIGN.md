# 设计规范

本文件是全站界面的唯一规范。4.0（2026-11-01）把外观换成**暖亮浮动面板**，结构与交互沿用 2.0 参照 Plain 建立的外壳、清单、记录页与设置区。页面仍分两类：**干活页**（清单、详情、助手对话、设置）按第 1–11 节，克制、保持密度；**展示页**（工作台、开发概览、开发排期及以后各领域的概览）按第 12 节，负责“眼前一亮”。两类共用令牌、外壳与组件。实现时只用这里的令牌（`apps/web/src/assets/theme.css` 中的 CSS 变量），不写新的取值；需要新令牌时先改本文件。

## 1. 原则

1. **白色面板浮在暖色渐变上。** 页面底 `--page-backdrop` 是奶白到强调色淡色的斜向渐变；图标栏、二级菜单、内容面板都是浮在上面的圆角面板，彼此留缝，不贴边、不画粗边框。
2. **只有墨黑、白与一种强调色。** 墨黑做主按钮、选中的模块与焦点卡片；强调色（`--accent`，默认明黄）标出“当前、正在进行、下一个”，如选中的菜单项、进行中的阶段、主角卡；其余是暖灰阶。语义色相（第 2.2 节）只用于状态与身份，不做装饰。
3. **胶囊与大圆角。** 按钮、页签、筛选、进度条、状态标签一律胶囊形；浮动面板圆角 24，展示页卡片圆角 28。未开始、计划中、剩余的部分用斜纹 `--hatch` 表示，不用灰块。
4. **大数字用细体。** 展示页的关键数字 48–64px、字重 200–300，单位小一号跟在后面；干活页的标题与正文不加粗，层级靠字号和位置。正文 14px。
5. **每个可交互元素都有短促、一致的反馈。** 悬停 75ms 换底色，弹层 150ms 位移 4px 淡入；不做弹跳、上浮、发光。
6. **键盘优先。** 主要操作都有快捷键，并在按钮、菜单里用 `kbd` 标出来。
7. **企业密度只在干活页。** 表格行高 44px、菜单项 32px；展示页留白多、一张卡片讲一个结论。

## 2. 颜色

### 2.1 角色

每种色相（neutral、blue、green、purple、red、yellow）都有同一组角色，CSS 变量为 `--<色相>-<角色>`：

| 角色                  | 用途                                       |
| --------------------- | ------------------------------------------ |
| `bg-1` / `bg-2`       | 整块浅底：页面、色带、备注块               |
| `fill-1/2/3`          | 标签底、按钮底、悬停与选中（数字越大越深） |
| `border-1/2/3`        | 描边：分隔、输入框、强调描边               |
| `text-1` / `text-2`   | 在浅底上的深色字 / 强调字（链接、标签字）  |
| `icon-1` / `icon-2`   | 图标                                       |
| `solid-1` / `solid-2` | 实心按钮、徽标、进度（2 为悬停或按下）     |

### 2.2 语义（固定，不挪用）

| 用途                         | 取色                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------- |
| 页面底 / 面板                | `--page-backdrop` 渐变 / `neutral.bg-1`（浮动面板为半透明白 `--surface`）    |
| 正文 / 次要 / 辅助           | `neutral.text-1` / `neutral.text-2` / `neutral.text-3`                       |
| 分隔线 / 输入框边 / 强调边   | `neutral.border-1` / `neutral.border-2` / `neutral.border-3`                 |
| 悬停 / 选中                  | `neutral.fill-1` / `neutral.fill-2`                                          |
| 主按钮                       | 墨黑 `neutral.solid-1` 底、白字，悬停 `neutral.solid-2`（4.0）               |
| 链接、焦点环                 | blue（链接 `text-2`，焦点环 2px `solid-1`）；展示页卡片里的“查看…”链接用墨黑 |
| 当前、进行中、下一个         | 强调色 `--accent` 底、墨黑字（选中菜单项、进行中阶段、下一个里程碑、主角卡） |
| 已完成、AI 建议与 AI 图标    | green                                                                        |
| 内部备注、测试数据、需要留意 | yellow                                                                       |
| 等待用户决定、状态事件色带   | blue `fill-1` 色带                                                           |
| 延误、错误、删除             | red                                                                          |
| 自定义类别（标签、模板类别） | purple 及其他色相，由用户选择                                                |

阶段状态：未开始 neutral、进行中 blue、已完成 green、已延误 red、已取消 neutral（删除线）。

### 2.2.1 身份色（2026-10-17 增补）

Plain 不“素”，靠的不是装饰，而是每一行、每一条消息都带着几处**身份色**：人有自己颜色的头像，类别有图标，优先级有记号。身份色只标识“是谁 / 是哪一类”，固定不变，与第 2.2 节的状态语义互不挪用。实现集中在 `components/base/identity.ts`，页面不各自取色。

| 对象     | 呈现                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 人员     | 方形头像（首字、`solid-1` 底）+ 名字；色相由名字散列到 blue / green / purple / red / yellow，同一人永远同色；未分配显示虚线空头像 |
| SAP 模块 | 标签（`fill-1` 底、`text-1` 字）：FI/CO 系 green、SD blue、MM purple、PP yellow，其余按名称散列；同一模块全站同色                 |
| 开发类型 | 彩色小图标 + 文字：报表 blue、功能 purple、接口 green、增强 yellow                                                                |
| 优先级   | 记号 + 文字：高为 red 圆形感叹号、中为 yellow 信号格、低为 neutral 信号格                                                         |
| 助手     | green `solid-1` 方形头像加闪光图标；助手给出的可点建议是 green `fill-1` 小按钮（`text-1` 字）                                     |

开发清单的行是两行：第一行开发名称（14px semibold），第二行业务功能点摘要（12px `text-2`，单行截断）；行高 `--control-table-row-double`（56）。

助手页时间线：用户消息左侧是用户头像，助手回复左侧是助手头像；等待用户回答的问题上方是 blue 色带“需要你决定”；运行结束后，成果下面给出 green 建议按钮（打开成果、继续追问的常用说法）。

### 2.3 配色主题（4.0）

不提供深色模式。用户可在头像菜单的“配色”里一键更换配色，换的是强调色与底色渐变，其余令牌不变。配色写在 theme.css 的 `[data-theme='<配色>']` 中，由 `services/theme.ts` 按“浏览器 + 用户”记在 `localStorage`，挂载前设到 `<html data-theme>`。

| 配色           | `--accent` | `--accent-hover` | `--accent-wash`（渐变终点） |
| -------------- | ---------- | ---------------- | --------------------------- |
| 明黄（默认）   | `#F2C94C`  | `#E6BB36`        | `#F7E7A8`                   |
| 珊瑚橙 `coral` | `#FF9F5A`  | `#F58E45`        | `#FAD9BE`                   |
| 薄荷 `mint`    | `#8FD9A8`  | `#78CC95`        | `#D3EEDB`                   |
| 天蓝 `sky`     | `#8FB4FF`  | `#779FF2`        | `#D7E3FB`                   |
| 丁香 `lilac`   | `#C3A8F0`  | `#B293EA`        | `#E7DCF8`                   |

强调色上的文字一律墨黑 `--on-accent`；强调色只作底色，不作文字色（对比度不足）。新增配色时同时给三个值，并检查强调色与墨黑字的对比度 ≥ 4.5:1。

## 3. 字体

- 无衬线：Inter 可变字体（随项目部署，`@fontsource-variable/inter`）加苹方 / 微软雅黑；代码与 SAP 对象名用等宽字体。
- 字号：11（快捷键）、12（表头、标签、说明）、14（界面与正文默认）、16（文档阅读正文）、20（面板与卡片标题）、24（页面标题）、32（登录页等少数场合）；展示页另有 40、48（问候语）、64（关键数字）。
- 字重：regular 400 / medium 475 / semibold 550；展示页的大数字与问候语用 light 300 或 extralight 200。页面标题与卡片标题用 regular；菜单选中项、表格主列、属性面板标签用 semibold。

## 4. 布局

### 4.1 外壳


- **浮动外壳**（4.0）：图标栏是一条半透明白色胶囊竖条（`--surface`、圆角 24），二级菜单是一块半透明白色浮动面板（圆角 24），内容面板为白色（展示页为透明，卡片直接浮在渐变上），三者与窗口边缘、彼此之间都留 8px 缝。
- **图标栏**（56px）：模块入口为 32×32 圆形图标按钮，选中为墨黑底、白图标；悬停时显示深色提示。顺序：工作台、项目、交付、设置（2026-11-01，roadmap 3.1）；点模块图标打开它的第一页，交付打开开发概览（没有其查看权限时打开开发清单）；底部为通知（铃铛，向右弹出通知列表；提醒上线前显示空状态说明，届时铃铛加未读角标）、搜索与头像菜单。二级菜单收起时点模块图标，跳转的同时展开菜单。
- **二级菜单**（248px）：顶部是企业名称与平台名称（身份，不可点击）和收起按钮；下面是当前模块的菜单（设置模块另有搜索）。工作台只有一页，不显示二级菜单，也没有收起与展开按钮（用户 2026-11-01 要求）。菜单项高 32、胶囊圆角，左图标右计数；未选中为 `text-2`，选中为强调色底、墨黑字、semibold。分组标题 12px、`text-1`、semibold，上方 `border-1` 细线，右侧折叠箭头，组内菜单缩进 8px（第 4.2 节）。

## 6. 页面模式

### 6.1 列表页（开发清单等）

页面标题与主按钮在页头（第 4.1 节）；内容区第一行依次是视图页签、搜索框（弹性宽度 180–420）、“筛选 F”“显示 V”与刷新，窄时换行；然后是表格。批量操作出现在选中行之后的浮动操作条里。

### 6.2 设置（总览与子页面）

`/settings`，图标栏的“设置”打开这里。居中一栏，最大宽 760；分组标题 16px 加一句说明，下面两列卡片（图标方块 + 标题 + 一句说明，规划中的页面带“规划中”标签），分组之间用 `border-1` 细线分隔。

子页面统一由 `features/settings/SettingsPage.vue` 排版：可选的“← 返回”、24px 标题与一句说明、右侧操作；表单页最大宽 760，列表页（`wide`）最大宽 1120。内容是 `SettingsCard`：带标题与一句说明的白色卡片，每个设置项为 `SettingsField`（左侧名称与说明、右侧控件），卡片底部右下角的“保存”只保存本卡片，没有改动时不可点。列表页（2026-10-29 用户确认，以“大模型”为准）为“一行概要（如当前默认）→ 工具行（搜索框、筛选下拉、右侧主按钮）→ 设置列表表格（第 5 节）→ 表格下方说明”，新增与编辑在右侧抽屉（第 5 节）里进行，不用对话框；对话框只用于确认、登录 SAP、复制等一次性的小操作。页面用 `SettingsPage` 的 `list`（最大宽 1600，与大模型一致）与 `drawer`（抽屉打开时让出宽度）；表格、抽屉、⋯ 菜单与离开前询问由 `features/settings` 的 `useDrawerLeave.ts`、`SettingsDrawer.vue`、`SettingsRowMenu.vue` 与 `settings.css` 的 `.s-table*`、`.s-drawer*` 提供，页面不另写同类样式。设置区的列表全部按此实现（第 12 批）：大模型、成员与权限、SAP 系统、用户、角色与权限、职位、客户、项目、我的 SAP 凭据、SAP 系统一览；用户、角色、项目点行打开抽屉（用户、角色用宽抽屉），原用户、角色详情页删除；只读的列表（SAP 系统一览）没有抽屉。团队与干系人、计划与健康这类以设置卡片为主的页面，卡片照旧，其中的列表（客户方联系人、里程碑）用同样的表格，前面是 16px 标题与一句说明（`.s-list-section`），新增、编辑与更新健康度在抽屉里。原生表单控件统一用 `settings/settings.css` 的 `.s-input`、`.s-select`、`.s-textarea`、`.s-check`。尚未开放的页面显示“规划中”。

### 6.3 记录页（开发项与设计 / 开发助手）

开发项的设计助手与开发助手是同一个记录页的两个页签，地址仍为 `…/development-items/:itemId/design` 与 `…/development`（第 4 批决定保留地址，旧链接不需要跳转）。

- **顶栏**（48px，`--layout-record-bar`）：返回开发清单、编号标签与标题、“设计 / 开发”分段页签、当前对话（点开为对话列表，可切换与改名）；右侧为资料、新对话、开发项信息开关、成果面板开关、⋯。窄屏分两行：标题与操作一行，页签与对话一行。
- **时间线**（左，阅读宽度 760）：
  - 用户消息为 `neutral.fill-1` 消息块（圆角 8、14/24）；助手回复为正文排版，不套块。
  - 运行步骤、实时状态、待决定问题、测试数据授权、成果卡片沿用原有组件与流式机制，只换外观。
- **输入框**：助手的主要工作是对话，输入框常驻底部，是白底、圆角 12、`floating` 阴影的浮动卡片，聚焦时 1px `focus` 描边；R 聚焦输入框，U 上传资料，Esc 停止生成。
- **成果面板**（中，可拖动宽度）：功能说明书或开发方案与代码，一行工具栏加可拖动宽度的目录。
- **开发项信息**（右，384px，`--layout-details`）：基本信息、开发对象、业务功能点，各分组可折叠；开关状态按人记住。窄屏时与对话、成果面板三选一。

### 6.4 工作台首页与项目

工作台是展示页，按第 12 节实现，内容与分层见第 12.4 节。我的项目页为页头、搜索框与同样的项目行；项目详情为页头（编号与状态标签）加可折叠的“项目概览”属性分组。

### 6.5 登录与修改密码

渐变底 `--page-backdrop` 上居中一张浮动卡片（最大宽 420、圆角 28、半透明白 `--surface-strong` 加亮边、`--shadow-panel`）：品牌（墨黑圆形标志、强调色字母）、32px 细体标题、一句说明、胶囊输入框（高 48）与墨黑胶囊主按钮（高 48）；“无法登录？”为次要文字色。首次登录的修改密码页同样是一张卡片；个人设置里的“账号安全”是同一表单，不套卡片，控件沿用干活页样式。

## 7. 动效

- 只用三档时长：75ms（悬停与按下换色）、150ms（多数过渡、弹层）、300ms（对话框、折叠展开）；侧滑面板用 400ms 的 `panel` 曲线。
- 弹层朝弹出方向位移 4px 加淡入；对话框从下方 16px、缩放 0.96 进入；折叠为高度动画；加载用骨架屏（透明度呼吸，不用渐变流光）。
- 列表和面板切换只做淡入，不做依次进场。
- 系统开启“减少动态效果”时，只保留透明度变化。

## 8. 可访问性

正文对比度 ≥ 4.5:1，控件边框与图标 ≥ 3:1；所有可交互元素有可见焦点环（2px `blue.solid-1`）；不能只用颜色区分状态（标签带文字）；图标按钮有可读名称；快捷键不抢输入框里的按键。

## 12. 展示页：暖亮仪表盘（4.0）

3.0（2026-10-31）的“柔和卡片便当格”在 4.0 换成暖亮语言：卡片不再放在灰色画布上，直接浮在页面渐变上；参照 Nixtio 为 Crextio 做的仪表盘，只借语言，不复制布局、标志与文案。

### 12.1 原则

1. **首页是封面。** 每张卡片只讲一个结论加一个数字，点开才是明细（下钻到清单或概览）。
2. **两层。** 页面渐变 → 卡片 `--dash-card`（半透明白 `--surface`，1px `--surface-edge` 亮边，圆角 28，`--shadow-soft`）。没有画布层，卡片里不再放卡片。
3. **一页一张强调色主角、一张墨色卡。** 主角用 `--dash-hero`（即强调色，墨黑字）；墨色卡 `--dash-ink` 放“本周要点”。其余卡片一律半透明白。
4. **超大细体数字。** 页首的关键数字 64px、字重 200；卡片里的数字 40–48px、字重 300；单位小一号跟在后面，等宽数字、紧字距。
5. **胶囊进度与斜纹。** 阶段条、进度条、负载条是胶囊；已完成为墨黑、进行中为强调色、未开始为斜纹 `--hatch` 加细边。
6. **趋势徽标说好坏，不说涨跌。** 胶囊徽标带箭头与变化量；好消息绿、坏消息红、无变化灰。没有可信的比较基准就不显示徽标。
7. **12 栏便当格。** 卡片按 3 / 4 / 6 / 8 / 12 栏拼行，同一行等高；≤1280px 两张一行，≤760px 一张一行。
8. **动效只做入场。** 数字卡淡入并上移 4px（300ms），折线描绘一次（900ms）；不弹跳、不发光、不循环；“减少动态效果”时不播放。

### 12.2 组件（`apps/web/src/components/dashboard/`）

| 组件            | 用途                                                                                                                                                                                                                                                            |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DashCard`      | 卡片：20px 标题（可带说明）、右侧操作（圆形箭头按钮或文字链接）、内容；`tone` 为 `hero` 或 `ink`                                                                                                                                                                |
| `DashMetric`    | 指标卡：标签、数字与单位、趋势徽标、一行说明；传 `open` 时整卡可点、下钻清单                                                                                                                                                                                    |

| `MilestoneRail` | 里程碑进度轨：日期按比例，今天之前实心，背后淡色月份；节点为已达成、未到、一周内到期（黄圈）、已延期（红底）；名称在轨下分最多三行避让；顶部一句“已达成 n / N，下一个：…”；`cards` 另列后续几个里程碑卡（下一个为强调色底）。用于工作台、开发概览与“计划与健康” |

图表色按 `--chart-1`（墨黑）… `--chart-5`（红）的顺序取，强调色 `--accent` 用于面积填充与“当前”；红只用于超载、风险；热力格为强调色的四档深浅，有风险的格子加红框。

### 12.4 工作台

页首（4.0）：48px 细体问候（上午好 / 下午好 / 晚上好，姓名）、日期 · 当前项目 · 客户；右侧次按钮“开发概览”、主按钮“打开开发清单”。项目层时，下面一行是**阶段胶囊条**（六个 Activate 阶段：已完成墨黑、当前强调色并写“进行中”与自报健康、未开始斜纹）与三个 64px 细体**关键数字**（开发完成率、距开发冻结、距上线，可点的下钻）。再下面是卡片，分层见[路线图](roadmap.md)第 6.6 节，层由权限与数据决定：

| 行  | 卡片                                                                                                                              | 出现条件                                                                                  |
| --- | --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 1   | 交付趋势（剩余人天与到冻结的理想线）· 开发完成（环形，附风险开发项）· 冻结前节奏（近 4 周均值对所需、本周完成）· 本周要点（墨色） | 项目层：持 `project.plan:edit`、`project.member:manage`，或开发概览默认视角为项目、开发组 |
